# payloads: that one diffs the re-encoded wire bytes, this one the full walk of the

# other, so a camp explained there is not automatically explained here.

# Why this file exists at all: `oracle/policy.yaml`'s allowed divergences are keyed to an
# input FILE, which works for the hand-written gates and cannot work over a fuzzed corpus

# reads as a hard divergence. A camp signature does not depend on which input produced it.
#
# A camp belongs here ONLY once it is explained: a catalogued finding, a legal divergence,
# or a benign soft axis. Anything else is reported as NEW and the run exits non-zero.
