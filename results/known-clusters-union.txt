# Accounted-for cluster camps of the UNION engine -- the baseline `oracle/cluster.py --baseline`
# diffs the nightly's union corpus against (corpus/interesting-union, roster built against
# schema/probe-union-deep.sofab.yaml).
#
# It is a separate file from results/known-clusters.txt because a camp signature is a
# (driver-set, verdict) partition over ONE roster build: the same partition means something
# different under another schema, and the two corpora are not replayed against each other.
# The rules of results/known-clusters.txt apply unchanged: a camp belongs here ONLY once it is
# explained, a FIXED camp is deleted rather than kept, and a driver moving between camps is
# real movement. Format: <signature>  # <label>
